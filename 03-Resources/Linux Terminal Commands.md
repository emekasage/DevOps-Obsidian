### Connecting to the server
```
username@ip-address
password: [your-password]
```

#### Other Commands
```
pwd - print working directory
ls
whoami
hostname
clear
date
ip a - to see ip address
uptime
touch - quickly create an empty file
rm - removes files (but there's no recycle bin - be careful with it!)
history - shows every command you have run

cat /etc/os-release - this displays details about the OS (Ubuntu)
```
